## 🌟 ฟีเจอร์หลักของระบบ (Main Systems)

ระบบแบ่งหน้าจอและการทำงานออกเป็นโมดูลต่างๆ ผ่าน Dashboard กลาง โดยแอดมินสามารถ **เปิด/ปิด** หรือตั้งค่าแต่ละระบบได้แบบ Real-time จากหน้าการตั้งค่าหลังบ้าน:

### 1. 📝 ระบบสำหรับคนจดงาน (Add Work)
- แบบฟอร์มเพิ่มรายการการบ้านหรืองานที่ได้รับมอบหมาย
- ระบุวิชา, วันที่ส่ง, รายละเอียด (รองรับ Rich Text Editor), ชื่อครูผู้สอน, ช่องทางการส่ง
- กำหนดประเภทงานได้ว่าเป็น **งานเดี่ยว** หรือ **งานกลุ่ม**
- รองรับการอัปโหลดภาพประกอบตัวอย่างงาน (จัดเก็บผ่าน Supabase Storage)

### 2. 📋 พริมง่วงทวงบุญคุณ (Kanban Task Board)
- กระดานลากวาง (Drag & Drop) จัดการสถานะงาน 3 ขั้นตอน: **สิ่งที่ต้องทำ (Todo)**, **กำลังทำ (In Progress)**, และ **เสร็จแล้ว (Done)**
- คัดกรองหมวดหมู่งานอัตโนมัติ (งานเร่งด่วน, งานที่เลยกำหนดส่ง)
- คำนวณเปอร์เซ็นต์ความคืบหน้าของงานทั้งหมดในห้องแบบ Real-time พร้อมแถบ Progress Bar
- ดูรายละเอียดงานแต่ละชิ้นพร้อมภาพประกอบและปุ่มแก้ไขสถานะ

### 3. 🚀 ฟีดแชร์การบ้านและขอดูการบ้าน (Homework Solutions Feed & Request - "ลอกงาน")
- **โซเชียลฟีดสำหรับการเรียน:** พื้นที่สำหรับเพื่อนๆ ในการแชร์แนวทางการทำการบ้าน (Solutions) และโพสต์ขอดูตัวอย่างงาน (Requests)
- **มัลติมีเดียครบครัน:** อัปโหลดรูปภาพได้หลายรูป (Multiple Images Carousel) พร้อมรองรับวิดีโอประกอบคำอธิบาย (`video.js`)
- **ระบบแชทและความคิดเห็น:** สนทนาใต้โพสต์แบบคอมเมนต์กระทู้ สามารถตอบกลับ (Replies) และแนบรูปภาพในคอมเมนต์ได้
- **ระบบโต้ตอบ:** กดถูกใจ (Like) และกดรีโพสต์ (Repost)
- **รูปโปรไฟล์อัตโนมัติ:** สร้าง Avatar ตามชื่อเล่นหรือรหัสอุปกรณ์ด้วย Dicebear Avatars

### 4. 📅 ตารางสอนของห้อง 3 (Room 3 Timetable)
- ตารางเรียนประจำสัปดาห์ ม.2/3 คาบที่ 1 ถึง 8 พร้อมแถบพักกลางวัน
- **ไฮไลท์เรียลไทม์:** ไฮไลท์คอลัมน์คาบเรียนปัจจุบันและช่องวิชาที่กำลังเรียนอยู่แบบอัตโนมัติ
- **Responsive Views:**
  - *Mobile:* แสดงผลเป็น Daily Cards View พร้อมสีประจำวัน (เหลือง, ชมพู, เขียว, ส้ม, ฟ้า)
  - *Desktop:* แสดงผลเป็น Weekly Table View ครบทั้ง 5 วัน
- **Period Detail Modal:** หน้าต่างป๊อปอัปดูรายละเอียดวิชา, ครูผู้สอน, คาบเรียน, และเวลา
- **แชร์ตารางเรียน:** ปุ่มกดเพื่อคัดลอกตารางเรียนรายวันลง Clipboard พร้อมนำไปวางในกลุ่ม LINE ได้ทันที

### 5. 📖 ระบบแจกสรุปสอบ (Exam Summaries)
- ศูนย์รวมไฟล์และเนื้อหาสรุปก่อนสอบ ทั้งกลางภาคและปลายภาค
- รองรับไฟล์ PDF, รูปภาพสรุปหลายภาพ, และลิงก์สรุปภายนอก
- แยกหมวดหมู่ตามรายวิชาและ **เทอมการศึกษา** (Term 1 / Term 2)
- **Countdown Timer:** ระบบนับถอยหลังสู่วันสอบจริง ซึ่งซิงค์วันสอบจากระบบหลังบ้านอัตโนมัติ

### 6. 🎯 เนื้อหาออกสอบ (Exam Topics & Scope)
- สรุปขอบเขตเนื้อหาที่ออกสอบของแต่ละวิชาอย่างละเอียด
- ระบุชื่อครูผู้สอน, จำนวนข้อสอบปรนัย (MCQ), และจำนวนข้อสอบอัตนัย (Essay)
- รองรับการกรองตามภาคเรียนและค้นหาตามชื่อวิชา
- เชื่อมต่อกับคำสั่ง LINE Bot เพื่อให้เพื่อนๆ เช็คแนวข้อสอบในแชทได้ทันที

### 7. 💸 ระบบกองทุนและทวงเงินห้อง (Class Funds & Expenses)
- ติดตามยอดเงินกองทุนห้องรายสัปดาห์ พร้อมยอดรวมสุทธิและยอดเงินสำรอง
- **ตารางเช็คชื่อการจ่ายเงิน:** ตรวจสอบสถานะการจ่ายเงินของนักเรียนเลขที่ 1 ถึง 52 ในแต่ละสัปดาห์
- **บันทึกรายรับ-รายจ่าย (Expenses):** บันทึกประวัติการซื้อของหรือค่าใช้จ่ายภายในห้อง
- หน้าต่างแสดงเลขบัญชีและคิวอาร์โค้ดพร้อมเพย์สำหรับโอนเงินเข้าห้อง

### 8. 🗳️ ระบบผลการเลือกตั้ง (Election)
- แสดงผลการลงคะแนนเลือกตั้งหัวหน้าห้องหรือตัวแทนแบบ Real-time
- แสดงภาพและข้อมูลผู้สมัคร พร้อมกราฟแสดงคะแนน
- หน้าแอดมินสำหรับเพิ่ม ลบ หรือแก้ไขข้อมูลผู้สมัคร

### 9. 👑 ระบบประเมินหัวหน้า (Boss Evaluation)
- ฟอร์มสำหรับเพื่อนๆ ในห้องร่วมประเมินการทำงานของหัวหน้าห้อง (ด้านความรับผิดชอบ, ความเป็นผู้นำ, การประสานงาน ฯลฯ)
- **Mental Health Hotline Modal:** หลังส่งแบบประเมิน จะมีหน้าต่างแนะนำสายด่วนฉุกเฉินและสุขภาพจิต (1323, 1669, ฯลฯ) เพื่อความผ่อนคลายและลดความตึงเครียด
- **Export รายงาน:** แอดมินสามารถส่งออกผลการประเมินออกมาเป็นไฟล์ **PDF** หรือ **CSV** ได้

### 10. ⚙️ ระบบหลังบ้าน & ความปลอดภัย (Admin Settings)
- **เปิด-ปิดระบบ (Feature Toggles):** แอดมินสามารถเปิด/ปิดแต่ละหน้าได้ทันที (Kanban, สรุปสอบ, เลือกตั้ง, ประเมินหัวหน้า, จดงาน)
- **โหมดปิดปรับปรุง (Maintenance Mode):** ปิดการเข้าถึงเว็บไซต์ชั่วคราวเมื่อมีการอัปเดตระบบ
- **แถบประกาศบนเว็บไซต์ (Announcement Bar):** ตั้งค่าข้อความแจ้งเตือนสำคัญที่จะแสดงด้านบนสุดของทุกหน้า
- **แบนเนอร์ป๊อปอัปหลายภาพ (Multi-image Popup Carousel):** ตั้งค่ารูปภาพประชาสัมพันธ์พร้อมแนบลิงก์ปลายทางเมื่อเข้าสู่หน้าเว็บ
- **จัดการข้อมูลโรงเรียน:** จัดการตารางเรียน (`/settings/schedule`), ตารางเวรทำความสะอาด (`/settings/cleaning`), และเครื่องแบบประจำวัน (`/settings/uniform`)
- **จัดการสถานะบอท:** ตั้งสถานะบอทออนไลน์/ออฟไลน์ พร้อมตั้งเวลาระบุการปรับปรุงระบบ

### 11. 🔔 ระบบตั้งเวลาแจ้งเตือนอัตโนมัติ (Automated Cron Jobs)
- ตั้งเวลาบรอดแคสต์ข้อความลงกลุ่ม LINE อัตโนมัติผ่าน External Cron Services:
  - `06:00 น.` — สรุปงานและการบ้านที่ต้องส่งวันนี้
  - `07:00 น.` — แจ้งเตือนเวรทำความสะอาดประจำวัน
  - `08:00 & 18:00 น.` — ร้องเพลงชาติ
  - `19:00 น.` — แจ้งเตือนงานค้างและงานที่ต้องส่งวันพรุ่งนี้
  - `22:00 น.` — บอทบอกฝันดีเพื่อนๆ

### 12. ✨ ระบบเข้าสู่ระบบเฉพาะนักเรียน (Student ID Authentication)
- **ระบบเฉพาะนักเรียนแยกเด็ดขาด:** เข้าสู่ระบบบน `https://primjaa.bungkii.app/login` โดยใช้ **เลขประจำตัวนักเรียน 5 หลัก** เท่านั้น (ตัวอย่าง: `30000`, รหัสเริ่มต้น `bBb@30000`) โดยตัดทางเข้าและแท็บผู้ปกครองออกจากหน้านี้อย่างสิ้นเชิง
- **Live Student Profile Preview:** แสดงชื่อ-นามสกุล, ชื่อเล่น, เลขที่ และรูปประจำตัวอัตโนมัติทันทีที่พิมพ์เลขประจำตัวครบ (แสดงผลเรียบง่ายสบายตาโดยไม่แสดงยศบนหน้าล็อกอิน)
- **จัดการสิทธิ์ตามยศในระบบ:** ผู้มีตำแหน่ง (SuperAdmin, Admin, Leader, Finance) สามารถแก้ไขและจัดการงานในกระดาน Kanban ได้ตามสิทธิ์อย่างครบถ้วน
- **ความปลอดภัยครบครัน:** ระบบซ่อน/แสดงรหัสผ่าน, แจ้งเตือน Caps Lock, และกู้คืนรหัสผ่านด้วยคำถามความปลอดภัย (พร้อมรหัสฉุกเฉิน 30000)

### 13. 👨‍👩‍👧‍👦 ระบบพอร์ทัลผู้ปกครอง & การแยก Domain (Parent Portal & Domain Separation)
- **แยก Domain ชัดเจน:**
  - 🏠 **ผู้ปกครอง:** `https://kanbann.bungkii.app` (หน้ารวม, การบ้าน, บัญชีเงินห้อง, สรุปสอบ, คู่มือ)
  - 🎓 **นักเรียน:** `https://primjaa.bungkii.app` (กระดาน Kanban, เพิ่มงาน, สรุป, ตารางเรียน, เลือกตั้ง)
- **คู่มือการใช้งานสำหรับผู้ปกครอง (`https://kanbann.bungkii.app/manual`):** แนะนำ 6 ฟังก์ชันหลัก, วิธีติดตั้งแอปลงบนหน้าจอมือถือ (PWA: iOS Safari & Android Chrome), และคำถามที่พบบ่อย (FAQ)
- **ซิงค์สถานะงานสด:** เมื่อลูกกด "เสร็จแล้ว" (Done) ในฝั่งนักเรียน หน้าจอของผู้ปกครอง (`/assignments`) จะขึ้นสถานะ **"✅ น้องทำเสร็จแล้ว"** ทันทีแบบเรียลไทม์
- **แถบสถิติเฉพาะของลูก:** สรุปเปอร์เซ็นต์ความคืบหน้า (Progress Bar) และตัวกรองดูเฉพาะงานที่ลูกยังไม่ได้ทำ

### 14. ☁️ โครงสร้างการจัดเก็บและอัปโหลดไฟล์ (Storage & Upload Architecture)
- 🖼️ **รูปภาพ (Images - JPG, PNG, WEBP, GIF):** อัปโหลดตรงเข้า **ImgBB API** ผ่านฟังก์ชัน `uploadImageToImgBB()` รวดเร็วและแสดงผลได้ทันที
- 📁 **ไฟล์ทุกชนิด & เอกสาร (All Files - PDF, Word, Excel, PowerPoint, Zip ฯลฯ):** อัปโหลดเข้า **Cloudflare R2 Storage** ผ่าน **Cloudflare Worker** ภายใต้โดเมน **`https://cdn.bungkii.app`** (`uploadFileToR2()`)
- 🤖 **Smart Uploader:** ฟังก์ชัน `uploadFileSmart(file)` สลับปลายทางอัปโหลดให้อัตโนมัติตามประเภทไฟล์ พร้อมโค้ด Worker สำเร็จรูปในโฟลเดอร์ [`cloudflare-worker-r2/`](file:///c:/Users/BUNGKII/Downloads/kanbann2-3/cloudflare-worker-r2)

## 🤖 แชทบอท LINE "พริมจ๋า" (LINE Bot Command Guide)

บอทพริมจ๋าเชื่อมต่อกับฐานข้อมูล Supabase และตอบกลับด้วย **LINE Flex Message** ที่ออกแบบมาอย่างสวยงาม สบายตา และมีปุ่ม Action ให้อย่างครบถ้วน:

### 📚 หมวดวิชาการและการบ้าน
| คำสั่ง | คำอธิบาย |
|---|---|
| `พริมจ๋า` | เรียกเมนูหลักของบอทพริมจ๋า (Flex Message) |
| `พริมจ๋า งานวันนี้` | ดูรายการการบ้านที่มีกำหนดส่งในวันนี้ |
| `พริมจ๋า งานค้าง` | ดูงานทั้งหมดที่ยังไม่ได้ส่งหรือเลยกำหนดส่ง |
| `พริมจ๋า สรุปงาน` | ดูรายการการบ้านและงานทั้งหมดในระบบ |
| `พริมจ๋าเนื้อหาออกสอบ <ชื่อวิชา>` | ดูเนื้อหาและขอบเขตข้อสอบ (ปรนัย/อัตนัย) ของวิชานั้นๆ เช่น `พริมจ๋าเนื้อหาออกสอบ คณิต` |

### 📅 หมวดชีวิตประจำวัน & ตารางเรียน
| คำสั่ง | คำอธิบาย |
|---|---|
| `พริมจ๋าวันนี้ใส่ชุดไร` / `พรุ่งนี้ใส่ชุดอะไร` | เช็คเครื่องแบบนักเรียนประจำวัน (หรือระบุ `วันจันทร์` - `วันศุกร์`) |
| `พริมจ๋า วันนี้ใครเวร` / `พรุ่งนี้ใครเวร` | เช็ครายชื่อเวรทำความสะอาดประจำวัน |
| `พริมจ๋า ต่อไปคาบไร` | เช็ควิชาเรียนในคาบปัจจุบันหรือคาบถัดไป พร้อมบอกเวลาและห้องเรียน |
| `พริมจ๋า วันนี้เรียนไร` / `พริมจ๋า พรุ่งนี้เรียนไร` | ดูตารางสอนเต็มวันของห้อง 3 พร้อมชื่อครูผู้สอน |
| `พริมจ๋า ดูไอดี` | ตรวจสอบรหัส Group ID หรือ Room ID ของกลุ่ม LINE ปัจจุบัน |

### 🗳️ หมวดโพลและการเลือกตั้ง
| คำสั่ง | คำอธิบาย |
|---|---|
| `พริมจ๋า เปลี่ยนหัวหน้า` | เปิดการ์ด Flex Message ให้เพื่อนๆ ร่วมโหวตเลือกตั้งหัวหน้าห้อง |
| `โหวตหัวหน้า: <ชื่อผู้สมัคร>` | ส่งคะแนนโหวตให้ผู้สมัครที่เลือก |
| `พริมจ๋า สรุปโหวตหัวหน้า` | สรุปคะแนนผลการเลือกตั้งหัวหน้าห้อง |
| `พริมจ๋า ส่งโพลล่าสุด` หรือ `โพลล่าสุด` | ดึงโพลที่แอดมินสร้างจากหน้าเว็บมาส่งลงกลุ่ม LINE เพื่อให้เพื่อนๆ โหวต |
| `โพลสรุปล่าสุด` | ดูผลคะแนนรวมของโพลล่าสุด |
| `โหวตโพล:<poll_id>:<option_index>` | คำสั่งลงคะแนนโหวตโพลผ่านปุ่มบน Flex Message |
| `สรุปโพล:<poll_id>` | ดูผลคะแนนของโพลตามรหัสที่ระบุ |

## 🚀 การติดตั้งและรันโปรเจกต์ (Installation & Setup)

### 1. โคลนโปรเจกต์และติดตั้ง Dependencies
```bash
git clone https://github.com/Bungkii/kanbann2-3.git
cd kanbann2-3
npm install
```

### 2. ตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables)
สร้างไฟล์ `.env.local` ในโฟลเดอร์ root ของโปรเจกต์:
```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# LINE Messaging API Configuration
LINE_CHANNEL_ACCESS_TOKEN=your-line-channel-access-token
LINE_CHANNEL_SECRET=your-line-channel-secret
```

### 3. ตั้งค่าฐานข้อมูลบน Supabase
นำไฟล์สคริปต์ SQL ในโฟลเดอร์ `/supabase` ไปรันใน **Supabase SQL Editor**:
- รันไฟล์ `setup.sql` หรือ `FULL_SETUP_2025.sql` เพื่อสร้างตารางทั้งหมด
- หากมีการอัปเกรดฟีเจอร์ ให้รันไฟล์ Migration ที่เกี่ยวข้อง เช่น:
  - `migration_homework_solutions.sql` & `migration_chat.sql` (ระบบแชร์การบ้านและคอมเมนต์)
  - `migration_add_exam_topics.sql` & `migration_add_exam_topic_counts.sql` (เนื้อหาออกสอบ)
  - `migration_add_expenses.sql` (รายจ่ายกองทุนห้อง)
  - `migration_add_system_settings.sql` (การตั้งค่าระบบและรูปป๊อปอัป)
  - `migration_add_boss_evaluations.sql` (ระบบประเมินหัวหน้า)

### 4. รัน Development Server
```bash
npm run dev
```
เปิดเบราว์เซอร์แล้วไปที่ `http://localhost:3000`

สำหรับการตรวจสอบ Build:
```bash
npm run build
npm run start
```

## 🔗 การตั้งค่า LINE Messaging API Webhook
1. สมัครบัญชีและสร้าง Channel (Messaging API) ที่ [LINE Developers Console](https://developers.line.biz/)
2. คัดลอก `Channel Access Token (Long-lived)` ไปใส่ในตัวแปร `LINE_CHANNEL_ACCESS_TOKEN` ของ `.env.local`
3. ในแท็บ **Messaging API**:
   - ตั้งค่า **Webhook URL** เป็น: `https://your-domain.com/api/webhook/line`
   - เปิดสวิตช์ **Use webhook**
   - ปิด **Auto-reply messages** ใน LINE Official Account Manager เพื่อให้บอทพริมจ๋าตอบได้อย่างราบรื่น

## ⏰ การตั้งค่าระบบเตือนอัตโนมัติ (Cron Jobs)
โปรเจกต์มาพร้อมกับสคริปต์ `setup-cron.js` ที่ช่วยลงทะเบียนคิวงานกับบริการ [cron-job.org](https://cron-job.org/):
```bash
node setup-cron.js
```
Endpoint ต่างๆ ของระบบแจ้งเตือนอัตโนมัติประกอบด้วย:
- `/api/cron/morning` — แจ้งเตือนงานตอนเช้า (06:00 น.)
- `/api/cron/cleanup` — แจ้งเตือนเวรประจำวัน (07:00 น.)
- `/api/cron/bot-anthem` — ร้องเพลงชาติ (08:00 และ 18:00 น.)
- `/api/cron/evening` — สรุปงานตอนค่ำ (19:00 น.)
- `/api/cron/reset-uniform` — รีเซ็ตสถานะชุดประจำสัปดาห์
